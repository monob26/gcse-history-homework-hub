Late-answer semantics are deliberately preserved: the current server records an expired submission
as incorrect and advances the quiz, rather than raising an exception. The test chooses the genuinely
correct shuffled option, ages only the disposable fixture's timestamp, and checks both the response
and saved incorrect mark. This proves refusal of credit without changing the R4 timeout contract.

## Run the checks

```sh
npm ci --cache work/npm-cache
npm run test:db
npm run test:browser
```

Database tests require Python 3 and Docker. The runner creates a uniquely named PostgreSQL 17.6
container pinned by image digest, without network access, published ports or persistent storage. It
supplies a minimal `auth.users`/`auth.uid()` test dependency and platform roles/default grants, then
applies **every unchanged migration in filename order** and the fictional local seed. Historical
baseline assertions remain enabled. Tests use transactions and roll back; the runner removes its
container on success/failure. It accepts no hosted URL or credential. Host Docker may download the
pinned image before launching the network-isolated container.

This tests actual PostgreSQL grants, RLS and application functions, not a running Supabase Auth or
PostgREST service. It does not claim JWT validation, gateway schema settings, email delivery or Auth
rate limits. Existing R8 hosted evidence covers its own acceptance scope; R2/R11 limitations remain
separate. `bootstrap.sql` is test infrastructure and must never be applied to a hosted project.

Local browser tests default to system Chromium at `/usr/bin/chromium`. CI installs the version
matching the pinned Playwright dependency and sets `PLAYWRIGHT_USE_BUNDLED_CHROMIUM=1`. Existing
request interception continues to block external traffic or fulfil fictional mocked responses. No
application source, migration, hosted fixture or deployment was changed.
