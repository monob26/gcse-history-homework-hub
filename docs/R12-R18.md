## R17 hosted client IP evidence

The LIVE and TEST catalogs contain identical definitions of
`homework_private.code_request_bucket()`. It reads the request headers exposed to PostgreSQL,
prefers `CF-Connecting-IP`, and falls back to the final address in `X-Forwarded-For` if the
Cloudflare header is absent or empty. It canonicalises and hashes the selected address. Missing or
invalid addresses use one shared bucket. The prior TEST HTTPS response carried a Cloudflare Ray ID,
and Cloudflare documents that its edge sends `CF-Connecting-IP` to the origin.
[Cloudflare HTTP headers](https://developers.cloudflare.com/fundamentals/reference/http-headers/#cf-connecting-ip)

The Ray ID establishes Cloudflare involvement for that response. The catalog establishes how the
database selects the bucket. Neither shows which header values the hosted REST gateway passes to
PostgREST or which ingress routes can reach it. The published Supabase guidance found for request
forwarding covered self-hosted gateways or Auth. The hosted pupil RPC uses the REST Data API.
[Supabase self-hosted proxy guidance](https://supabase.com/docs/guides/self-hosting/self-hosted-proxy-https)
· [Supabase Auth rate limits](https://supabase.com/docs/guides/auth/rate-limits)

For independent verification, obtain written confirmation from Supabase Support for the TEST and
LIVE REST Data API endpoints covering these points:

- Whether every reachable route to the pupil RPC passes through an ingress that sets
  `CF-Connecting-IP` from the observed peer and strips or replaces client-supplied values.
- Whether any supported gateway route can omit that header, and what component sets the final
  `X-Forwarded-For` address in that case. Confirm whether that address reliably identifies the
  client and is protected from caller control.

If Supabase cannot guarantee those properties, review the fallback with Supabase and validate any
change in TEST before relying on the boundary for real pupil use. This follow-up used read-only
catalog evidence and existing test results.
